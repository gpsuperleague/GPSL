Season challenges

Defaults

Each club earns the per-challenge prize when a target is met. Set up to the max per window (default 10) Start and Mid challenges; the first club to complete the number needed (default 5) in a window automatically wins the big prize pack below — cash, owner credits, medical tokens, transfer fee discounts, appeal cards and draft tokens. If fewer challenges are set than the number needed, all of them must be completed. That club is paid instantly, items go to Club prizes, and every owner gets an inbox announcement (plus Discord if the news feed is live). Start = June–December. Mid = January–May.

Targets

Recheck all clubs scans every club’s season stats against these targets and pays any unpaid prizes (works even if the Start/Mid month window has already closed — for catch-up after you set challenges late).

Saved target templates

To save for future seasons: add/edit challenges in the list above first, then enter a template name and click Save as template. That snapshots every active target on the current season. Templates are not tied to a season, so they survive wipe/reset. Apply to Start or Apply to Mid adds only the target with the same name as the template. The other targets in that snapshot stay put, and challenges already on the season are not removed.

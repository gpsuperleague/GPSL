Formations catalogue

Build eFootball-style named formations. Slot role locks and allowed positions apply on Match Day whenever enabled formations exist in this catalogue. Global rule: CF + SS ≤ 2 (no CF/CF/SS). Mirroring (LB↔RB, LMF↔RMF, LWF↔RWF) is always enforced on Match Day saves.

    Pitch layout

    Click the role badge (e.g. CMF) to change that slot’s starting role (CMF → DMF). Drag the marker to move it. Attack is toward the top of the pitch (low Y). Click Save formation to persist.

    Big label = starting role. Small text under it = slot id (keep LMF / CMF / RMF — do not rename). Example 4-3-3: left & right stay CMF; centre starting role = DMF.

    Slots (11) — roles & owner swaps

    Slot id is the fixed hole (do not change). Starting role is what shows on the pitch. Untick Allow change to lock that role. When change is on, tick allowed swaps (starting role is always included). Example: start CF + tick only SS → CF or SS. For SS only: set Starting role to SS and untick Allow change. In 4-4-2 both strikers are separate slots (usually LWF and CF) — set rules on each.

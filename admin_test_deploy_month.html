Deploy month results

← Admin hub · also under Admin → Testing

What it does

  • Plays all scheduled league + cup fixtures for one GPSL month
  • Random scores, auto squad stats (goals match score), POTM per club
  • Skips inbox submit / confirm

Order & scope

  • League first, then cups by round
  • Cup draws → ET or penalties
  • Includes Playoffs (after May is locked and ties exist)

When the month finishes

  • Seeds 15 yellow + 1 red across that month’s fixtures
  • Discipline / bans apply as usual
  • If cards missing, run admin_testing_deploy_month_discipline.sql

2. Deploy results

Random scores 0–4 per team (league). Cups: random 90-min score; draws resolved by ET or pens. Clears any pending result submissions for those fixtures.

Type exactly: DEPLOY TEST MONTH

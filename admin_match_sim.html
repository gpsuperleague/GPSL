Match result simulation

← Admin hub · Owners get a Simulate button on My Club Fixtures when this is on. Turn off before the first proper live season.

Toggle

OFF

How it works

  • Uses each club’s saved matchday starting XI (else top 11 by Rating).
  • XI combined Rating decides favourites; star players nudge chances ~10%.
  • One owner click finalises the match (score, stats, MOTM, gates) in a few seconds.
  • Opponent is locked out while a simulation is running / once the fixture is played.

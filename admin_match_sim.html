Simulation rules

Cards are rolled per match: a fixed number of yellows, plus a % chance of one red.

Star players (rating ≥ threshold)

Higher ratings above the threshold hit harder. Each % only applies to its position group, and only when the player’s profile Position matches the pitch slot (out of position = no star boost).

How it works

  • Uses each club’s saved matchday starting XI (else top 11 by Rating).
  • XI Rating sum picks a win band; star power can nudge those %.
  • Stars (default 79+): goal = LWF/RWF/SS/CF · assist = LB/RB/CMF/AMF/LMF/RMF · concede = GK/CB/DMF — only if profile Position matches pitch slot.
  • Instant result finalises immediately; Simulate match plays a ~20s momentum graphic first.
  • Cards = yellows per match + % chance of one red.

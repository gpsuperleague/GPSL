Close Finances

Close season finances

Runs end-of-season money for the current season, in order:

  1. Wage bills — player wages, manager salary (weekly × 52), 34+ fee, star tax
  2. Stadium maintenance — capacity × ₿1,500 × maintenance % (Stadium costs)
  3. Debt interest — bank rate (default 5%) on overdrawn balances
  4. FFP — flat ₿50M if balance ≤ −₿100M; then release highest-MV players @ MV until balance > −₿99,999,999; buy embargo for the next transfer window
  5. Balance interest — 0.5% credit on positive balances only
  6. Finance archive refresh — updates Season accounts snapshot (so Archive-before-this is safe)

Each line is skipped if already posted for that club/season. Ensure these patches are applied in Supabase: close_finances_eos_interest_ffp.sql, stadium_maintenance_eos_and_season1_backfill.sql, ffp_50m_mv_release_embargo.sql, manager_season_salary_wage_bills.sql, and if debt/FFP inserts fail a type check, re-run season1_eos_interest_ffp_backfill.sql ( widens entry types ) or competition_finance_ledger_entry_types_repair.sql. Rates/threshold live on gpsl_bank_account.

Re-settle wages after Close Finances

Close Finances charges wages, manager salary, 34+ fee, star tax and the Fan Favourite subsidy once per club. This works them out again from the current squad and settings and posts only the difference. It only touches clubs whose wages were already posted. Run it before End Season.

Stored contract wages = same maths as Close Finances (each player's contract wage; wage % only where none is stored). Use this after squad changes.
Current wage % = reprice every player at today's Wage % × market value, for this season's bill only. Stored contract wages are not overwritten. Use this after changing Wage %.

End-of-season debt interest and balance interest can be corrected too. FFP is never changed automatically; clubs whose FFP result would change are flagged. SQL (once): supabase/sql/patches/season_upkeep_resettle_20260928.sql

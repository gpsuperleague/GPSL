Club Management

Soft-archive keeps the club row and all history (seasons, trophies, transfers). Archived clubs are vacated (no owner) and hidden from normal pickers. New clubs start unowned — assign via Owners or leave for club auction.

Add club

Creates a vacant club. Upload the badge below (or kits/stadiums via Club Management menu) using ShortName.

Archive / restore

Archive vacates any owner. Unarchive restores the club as vacant for reassignment.

Upload club badge

Download the crest from the club’s Wikipedia page (PNG or SVG), then upload here. Saved as images/club_badges/{ShortName}.png on GitHub via club-stadiums-sync + GITHUB_TOKEN. SVG is converted to PNG in the browser. After code updates: redeploy club-stadiums-sync (paste supabase/functions/club-stadiums-sync/index.ts, JWT off).

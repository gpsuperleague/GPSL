Events appear on the owners' Season Calendar in the GPSL month they fall in. Auctions can start by themselves: tick Auto-start and the auction is switched on with its clock set ahead of time (owners get the usual inbox + Discord "scheduled" notice), then bidding opens at the start time and closes at a secret time the next evening (18:50–18:59:58 for a 19:00 start). Challenge windows and deadlines come from Challenge Admin automatically; special auctions from the Special Auction page.

Use a 19:00 UK start for the normal Day-1 / Day-2 rhythm. If another auction of the same type is live at switch-on time it is left alone and this event is marked failed.

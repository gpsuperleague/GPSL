## Quick map

1. **Before KO** — availability → home proposes (30‑min mutual) or poke → away accept/counter → optional Discord lock  
2. **Agreed** — check-in ±10 · play 30‑min block · Play now (earlier 10‑min) · mutual new time · drop  
3. **Problems** — one-sided no-show ladder · both miss fine · catch-up reset  
4. **Month lock** — no proposal ₿2.5m · late ₿1m · reply warn→₿2.5m · holiday corridor · both system OFF = mutual forfeit

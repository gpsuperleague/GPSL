Owners,

The **Match arrangement systems** poster is updated for the latest rules.

What’s new
• **Mutual new time** — still **one free** per fixture (both confirm; no allowance used)
• **Play now** — can be used **again** after that free new-time if you’re both ready (still no allowance)
• **Attempt 3+ no-show ladder** (GPSL arranging only):
  - Attempt = each distinct agreed kick-off
  - Attempts **1–2**: recorded no-show → unfinished at next month lock = **3–0 + ₿2.5m**
  - Attempt **3+**: first no-show per club = **warning**; each further miss by that club = **₿1.5m**
  - First fine starts **open play** (propose/accept) for **2 more GPSL months**
  - Still unplayed at that deadline → more no-shows forfeits; equal counts → both **0–0 + ₿1.5m each**
  - Both miss check-in = no fine; pick a new time

The three arrange lanes (full manual / GPSL full / GPSL via Discord) are unchanged.

Full detail: Learning GPSL → Fixtures & results, and the Schedule page banner when attempt 3+ applies.

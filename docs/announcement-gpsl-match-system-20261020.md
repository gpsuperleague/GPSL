# Announcement — GPSL match system toggle (layman)

**Suggested Natter / Discord title:** New option: arrange matches the old-fashioned way (with a price)

---

Owners,

We’ve added a simple switch on **Owner Details** called **GPSL match system**.

**Default = ON** (recommended).  
That’s the system you already know: home proposes, away replies, deadlines, Discord lock if you already agreed a time, check-in, the lot.

**OFF** means you step out of that safety net for that half of the season.

### How OFF works
- You only get the “manual” lane when **you and your opponent are both OFF**.
- Then there’s **no propose / reply clock** on that fixture. Arrange however you like (Discord, etc.).
- When you’ve played, enter the result on **Match Day** as normal during that GPSL month.
- If the game is **still not played when that month locks** (Thursday 19:00 UK):
  - **Mutual forfeit** — **0 points each** (not a draw)
  - **₿2.5m fine each**
  - In **cups**, **both clubs are out**; the team that would have played the winner gets a **bye**

If **either** club has GPSL match system **ON**, the normal GPSL arranging rules apply.

### When you can change it
- **July** — set your preference for **August–December**
- **December** — optional change for **January onward** (kicks in from January; Aug–Dec stays as it was)
- If you do nothing in December, your Aug–Dec choice carries on

This sits **alongside** the normal system — it doesn’t replace it. Leave it ON unless you and like-minded opponents really want the black-box route.

Full detail: Learning GPSL → Match scheduling, and Owner Details → GPSL match system.

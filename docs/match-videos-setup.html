Match videos — initial setup

GPSL checks Discord every 2 minutes (same idea as Discord Friendlies). You do not need a PC left on, and you do not run npm start or create a .env for a bot host.

Do the steps in order. Tick each one as you finish. Ignore anything about “always-on bot” / discord-bots/match-videos — that path is optional and not for you.

Step 1 — Discord category

  1. In your GPSL Discord server, create a category named e.g. Matchday videos.
  2. Under it, create text channels named after GPSL months, e.g. august, september, october, … (or August — either works).
  3. User Settings → Advanced → turn on Developer Mode.
  4. Right‑click the category → Copy Category ID. Keep that number.
  5. Ensure your GPSL bot can View Channel, Read Message History, and Add Reactions in that category.

Step 2 — Message Content Intent

  1. Open Discord Developer Portal → your existing GPSL bot app.
  2. Left: Bot → Privileged Gateway Intents → Message Content Intent ON → Save.
  3. If this is already on, skip.

Step 3 — Bot token in Supabase (you may have done this)

  1. Supabase Dashboard → Project Settings → Edge Functions → Secrets.
  2. Set / confirm:
    • DISCORD_BOT_TOKEN — your bot token (if you Reset Token, paste the new one here).
    • DISCORD_GUILD_ID — leave as-is if Discord features already worked. The secret preview can look “different”; that is normal.
    • DISCORD_MATCH_VIDEOS_CATEGORY_ID — new: paste the category ID from Step 1.
  3. You do not need DISCORD_MATCH_VIDEOS_INVOKE_KEY for this setup.

Step 4 — SQL patches (run both in SQL Editor)

  1. Run file: supabase/sql/patches/match_video_uploads_20260912.sql
  2. Run file: supabase/sql/patches/match_video_uploads_cron_20260912.sql
    This schedules a poll every 2 minutes and tries to reuse the Friendlies/News invoke key.

Step 5 — Deploy the Edge Function

  1. On a machine with Supabase CLI logged in, run: supabase functions deploy discord-match-videos-ingest
  2. If you do not use the CLI, deploy that function from your usual GPSL deploy method — same as you did for discord-friendlies-ingest.

Step 6 — Turn on auto-poll in Admin

  1. Open Admin → Match videos.
  2. Under Auto-poll, leave the URL as the match-videos function URL (prefilled / bootstrapped).
  3. Tick Enable auto-poll → Save auto-poll.
  4. Status should say invoke key is saved. If it says missing: open Admin → Discord Friendlies, save auto-poll there once (so the key exists), then re-run the cron SQL patch or Save again on Match videos.
  5. Optional: click Poll now to test immediately.

Step 7 — Test with a real upload

  1. As a club owner (Discord nick/tag must match their GPSL owner tag), post in the correct month channel using Discord’s link format:
  2. Message example: [ARS 2-0 CHE [SL-MD5]](https://youtu.be/xxxxx) The text inside the outer [] is the match name. Score is required and must match the confirmed result. Spacing is flexible: 2-0, 2 - 0, or ARS 2 CHE 0 all work. The URL in () is usually YouTube — that becomes the clickable Fixtures tick. League / division tags (verified against the fixture): SL SuperLeague · CA Championship A · CB Championship B + MD + number. Cups: S8 Super8 · PL Plate · SH Shield · BO Bowl · LC League Cup (+ QF/SF/F/R{n}). WC World Cup recognised later.
  3. Within ~2 minutes (or after Poll now): Discord ✅, Fixtures shows H/A tick, Finances shows ₿200,000 Matchday revenue (video) once.
  4. If it fails: Admin → Match videos → Recent ingest log shows the reason; or use Manual link.

What you can ignore

  • cd discord-bots/match-videos, .env, npm install, npm start
  • Any “host that stays online” / Railway / VPS for this feature
  • Creating DISCORD_MATCH_VIDEOS_INVOKE_KEY unless you later want a separate key

# Announcement — One-time match stats edit

**Image:** `docs/gpsl-match-stats-one-time-edit.jpg`  
**Suggested Discord title:** One-time stats edit (same GPSL month)

---

Owners,

You can now fix honest mistakes on match stats — once per club, per match.

How
• Match Day → pick a played fixture tagged “edit stats”
• Amend your club only (started/subbed, goals, assists, cards, rating, POTM)
• Save once — then that edit is used

Rules
• Score stays locked
• Window = the GPSL month when the result was posted (still the active month)
• Not necessarily the fixture’s own month if it was early/catch-up play
• Opponent does not need to re-confirm — your stats only

Use it for wrong scorers, missed cards, rating slip-ups. Don’t wait for month lock.

— GPSL

Month-end fixtures — gap analysis

Internal review of arrange / reply / check-in / catch-up (league + cups). Not a live DB audit.

Bottom line: Design is mostly sound (no mass 3–0 → catch-up; fines at lock; cups included). Biggest holes: fragile no-show idempotency SQL; catch-up stops enforcing reply/no-show later; cup brackets can stall; admin early-end may defer lock jobs.

Findings

CRITICAL No-show skip check — broken format string

Idempotency LIKE uses format('sched_checkin_lock:%s:%', month, fixture_id) — one %s, fixture_id unused, trailing % invalid/ambiguous. Note write correctly uses two %s. Risk: job errors or unreliable skip on re-run.

competition_enforce_scheduling_checkin_fines · match_scheduling_checkin_no_show_deferred.sql

  • Fix to format('…%s:%s%%', month, fixture_id) (or equivalent).
  • Admin repair scan for leftover no-shows still scheduled.

HIGH Catch-up replies — 24h with no month-lock bite

Docs say 24h replies in catch-up. Tracking/fines only apply while play month is open / for that month’s fixtures. After catch-up, overdue replies aren’t fined at later locks.

  • Track + fine catch-up overdue at each active month lock, or document as honour-only.

HIGH Catch-up one-sided no-show never auto-forfeits

Forfeit at lock only selects fixtures whose gpsl_month is the closed month. Miss on a catch-up kick-off can sit forever.

  • At each lock, forfeit catch-up fixtures with no_show_club still set.

HIGH Cup brackets can stall in catch-up

Same “no mass 3–0” as league — later rounds wait on winners. Ops risk for fixed-month cup rounds.

  • Auto-forfeit cups after N catch-up weeks, or admin resolve tool + playbook.

HIGH Admin early end defers lock jobs

Timeout fix returns lock_jobs_deferred: true. Fines wait for cron or “Run month lock jobs”.

  • UI: auto-chain / require run after early end; alert if job keys missing.

MEDIUM Recurring ₿10m Match Management

Documented; can stack every month while home never proposes (including catch-up). Away has no parallel duty until a proposal exists.

  • Cap repeats, stop once catch-up, or Inbox “will repeat” warning.

MEDIUM Mutual override across month lock

May not expire in lock jobs; kick-off may not re-validate catch-up window; can block catch-up reset.

  • Expire in lock jobs; re-validate on apply; allow reset to cancel pending.

MEDIUM Owned vs vacant linger

Vacants not fined (correct). Owned home still pressured to propose; match may wait for staff sim.

  • Exempt arrangement fine vs vacant; auto-sim / queue at lock.

MEDIUM Early-end vs arrangement windows · job race

Early lock shortens arrange time; concurrent tick+admin can double-run (notes usually save money).

  • Align late-fee boundary; insert job key first / advisory lock.

LOW Docs slip · cup gpsl_month null

Learning still says “league” for catch-up in one bullet. Cups without gpsl_month skip enforcement silently.

  • Align copy; admin health check for null month cups.

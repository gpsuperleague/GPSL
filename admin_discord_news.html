Discord News Feed

Channels

#gpsl-news — transfers (filtered), managers, owners, cups, titles, etc.
Transfer filter: age ≤20 need rating ≥70; age ≥21 need rating ≥76.
#gpsl-results — club league / cup match results as a daily digest (by division + matchday / cup round), not one Discord ping per fixture. Cron ~20:00 UTC; use Publish results digest now to flush early.
#gpsl-intl-results — international / World Cup results as a separate daily digest (same evening cron).
#gpsl-natter — owner Natter posts (text + image).
#gpsl-notifications — auctions, transfer window, month ticks, season start, challenges, nation pick turns (@owner), match reminders, OOC batch, vacant clubs.
#gpsl-tables — league table images when a GPSL month locks (SuperLeague + both Championships).
#gpsl-intl-tables — World Cup qualifying / finals group tables on the same month-lock (separate channel).
#gpsl-scheduled — club league / cup kick-offs when both owners agree the time (LEAGUE / CUP labelled).
#gpsl-intl-scheduled — international kick-offs when both national managers agree (separate channel).
#whos-who — live owner · club roster by division (posted once, then silently edited daily — no notifications).
League clinches — when a title / auto promotion / playoff place / relegation is mathematically certain: club inbox (+ broadcast for major outcomes) and #gpsl-news only. Use Scan league clinches to backfill.

Auto-post (no button)

Events are queued in the database. With auto-post enabled, Postgres calls the edge function as soon as something is queued (plus a 2-minute retry cron).

Manual Push uses your admin login (works even when auto doesn’t).
Auto-post uses a server-side invoke key stored in the database (set once in the SQL Editor — never pasted in this browser).
Also run security_hardening_safe.sql and enable pg_net.

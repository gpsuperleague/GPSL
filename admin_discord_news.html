First-time setup (webhooks, secrets, SQL, deploy)
  1. In Discord, create each channel above if missing.
  2. Channel settings → Integrations → Webhooks → New Webhook → copy URL (create the webhook inside that channel).
  3. Supabase → Edge Functions → Secrets (project-wide): paste each URL against the secret name in the table.
  4. Run SQL patches as needed: notifications / results digest / gpsl_discord_league_tables.sql / gpsl_discord_whos_who.sql / discord_scheduled_matches_20260904.sql / discord_intl_results_digest_20260904.sql / discord_intl_tables_20260904.sql / discord_member_joined_to_news_20260904.sql.
  5. Redeploy after edge code changes: supabase functions deploy discord-sky-feed
  6. Use Check routing, then Publish Who's Who now for the first roster post.

Transfer filter on News: age ≤20 need rating ≥70; age ≥21 need rating ≥76.

Auto-post

With auto-post enabled, Postgres calls the edge function when something is queued (plus a 2-minute retry cron). Manual Push still works via your admin login. The invoke key is stored server-side once in SQL Editor — never paste it in this browser. Also run security_hardening_safe.sql and enable pg_net.

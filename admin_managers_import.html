Update Managers list

Upload or paste a CSV (same columns as data/Managers.xlsx). Rows upsert by slug (from name). Existing contracts, wages (if signed), career stints, listings, and IDs are kept. New names are inserted as free agents. Managers missing from the file are not deleted.

Required headers (aliases accepted): Manager Name, Nation, Age, Possession, Quick Counter, Long Ball Counter, Out Wide, Long Ball, Overload. Optional: Previous Name (for renames — keeps the same manager id/contract/history), slug.

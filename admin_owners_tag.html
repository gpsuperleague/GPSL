Set owner tag

Defaults to owners with no registry Discord tag, or a tag that looks wrong (placeholder, email-shaped, email username, club code, or Clubs.owner mismatch). Join-flow accounts often have discord_user_id but an empty owner_tag — display names elsewhere can still show the email local-part via owner_registry_resolve_tag until you set a real tag here. Requires patches/admin_owner_set_tag.sql.

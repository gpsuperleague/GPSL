Tax %

Income tax %

League income tax on player spend — charged to the buying club when a purchase posts to the ledger. Applies to transfer fee + agent fee (transfer list deals) and special auction fees. Collected to the GPSL Central Bank (gov_income_tax). Set 0 to disable. Run patches/gov_income_tax.sql and patches/gov_income_tax_transfer_restore.sql (restores tax after prize-discount transfer ledger).

Season true-up (after changing the %)

Tax is charged when each purchase settles, so purchases made before you changed the % were taxed at the old rate. This re-taxes every purchase this season at the current % and charges or refunds each club only the difference. 1. Save the new % above. 2. Preview. 3. Apply. Safe to run again — clubs already level are skipped.

Agent fee %

Charged to the buying club on transfer list deals only, as a % of the winning fee, on top of the fee (transfer_agent_fee). The seller still receives the full fee. Income tax is then charged on fee + agent fee. Not charged on draft auctions, special auctions, foreign sales or contract releases. Set 0 to disable. Run patches/transfer_agent_fee_pct_20260928.sql once.

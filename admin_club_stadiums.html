Club stadiums

Nav: Admin → Season Break → Club Management → Download Club Stadiums

Stadium photos from StadiumDB are stored as images/stadiums/{ShortName}.jpg on GitHub (shown on stadium / club UI). Photos © their credited photographers on source pages — league UI reference use.

One-time setup (required)

GitHub deploy alone does not install the edge function. Until this is done, download buttons will fail to reach the function.

  1. Supabase Dashboard → Edge Functions → Create function
  2. Name exactly: club-stadiums-sync
  3. Paste all of supabase/functions/club-stadiums-sync/index.ts from this repo
  4. Deploy → Settings → turn OFF “Enforce JWT verification” (same as kits / GPDB scrape)
  5. Edge Functions → Secrets → ensure GITHUB_TOKEN is set (same PAT as club-kits-cof-sync)

See scripts/README_stadium_images.md.

Download stadiums

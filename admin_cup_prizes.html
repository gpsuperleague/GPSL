Cup prize money

Round fees are paid to both clubs when a tie is confirmed. League Cup stages: Last 64, Last 32, Last 16, QF, SF, Runner-up, Winner. The final pays separate Winner and Runner-up amounts. After changing League Cup stages, run patches/league_cup_prize_stages_r32_r16_20260925.sql then set amounts (and backfill played ties if needed). Use Save as reset template so cup amounts survive a full league reset (patches/prize_templates_survive_reset_20260925.sql).

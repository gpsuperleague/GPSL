Transfer window & engine

Draft auctions & schedule

Open/close the owner transfer market on Transfer window.

Player, manager, and club each have their own start/finish clock (can overlap). Save schedules each type you turn On to the next Day-1 19:00 UK slot (tomorrow if it is already after 19:00). Late start is separate: Day-1 tonight 19:00 UK (bidding live now) + usual Day-2 18:50–18:59 finish for that kind only. Requires patches/draft_schedules_per_type.sql.

Cancel open listings & bids

Soft-cancel only: open market / draft listings → Closed (not completed), active bids & pending direct offers → rejected. Completed sales are never touched. Run patches/admin_cancel_open_transfers.sql once if RPCs are missing.

Club auction

Turn Club auction on above and Save transfer settings to share the draft schedule (7pm UK open, random close). Then seed vacant clubs before owners bid. Requires patches/club_auction.sql.

Manager Market FA board

June / July / August / January should keep 10 free-agent managers listed (window_fa). Transfer engine tops up automatically; use these if the board is empty. Requires patches/manager_window_fa_board_fill_fix_20260815.sql then patches/manager_window_fa_cron_rewire_20260821.sql (re-attaches FA tick to the transfer engine cron).

Run transfer engine

Processes stuck listings and draft threads. Run admin_transferengine_run.sql once if the RPC is missing.

If player drafts stay Active after the random finish, the engine may be waiting on same-evening 7pm transfer-list auctions. Use Force settle player drafts (run patches/draft_settlement_skip_season_excluded.sql first if the RPC is missing). Manager auctions: patches/manager_draft_settlement_fix.sql then Settle manager drafts now.
